What the tests have turned up

Short write-ups of what measuring real chips has shown, each with its evidence. New ones also appear in the updates feed.

15 October 2026

NVIDIA's own fault patterns, caught on a real GPU

The self-test now plants faults shaped like NVIDIA's gate-level measurements. On an RTX 4090 the reference check alone flagged all 294.

11 October 2026

When ECC is off, the memory error counters cannot see anything

Two rented cards ran with ECC switched off, so their counters could not move. The tester now says so instead of calling them quiet.

10 October 2026

BF16 matrix multiplies on Intel AMX treat tiny inputs as zero

Above 16 × 16 × 16, BF16 matrix multiplies on AMX CPUs treat subnormal inputs as zero, whatever set_flush_denormal says.
